What people ask before they draw their first floor.

Contact us

Where is my building data stored?

In your own browser. Nothing is uploaded; export a project file to back it up or share it.

Does it replace a fire risk assessment?

No. It supports planning and drills; a fire engineer still signs off against your local code.

Can I set my own code limits?

Yes. Travel distance, minimum width, target time, walking speeds and spread rates are all settings.

Do maps from the old Python planner open?

Yes. Import the JSON file and its rooms, exits and distances come across.
